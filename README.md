# Pulse-Oximeter-PCB
Designed a 4-layer PCB for an ESP32-based pulse oximeter and heart-rate monitor using a MAX30102 sensor and SSD1306 OLED display. The board acquires SpO₂ and heart-rate data, displays the readings on the OLED, and includes power regulation, I²C communication, user push-buttons, and status LEDs. The schematic and PCB were designed using KiCad.

## Features

- ESP32 microcontroller
- MAX30102 SpO₂ and heart-rate sensor
- SSD1306 OLED display
- Push-button inputs
- Status LEDs
- 3.3 V power regulation
- I²C communication interface
- Compact 4-layer PCB layout
